# Deviloq

**ابنِ بورتفوليو يوضح أعمالك ورحلتك التقنية، وشاركه برابط واحد.**

[الموقع المباشر](https://mydevfoliohub.github.io/) · [أحدث إصدار Android](https://github.com/mydevfoliohub/mydevfoliohub.github.io/releases/latest)

![معاينة Deviloq](./social-preview.png)

## ما هو Deviloq؟

Deviloq منصة لإنشاء بورتفوليو للمطورين والمهتمين بالتقنية دون الحاجة إلى تعديل الكود. ينشئ المستخدم حسابًا، يضيف أعماله ومهاراته وما يتعلمه، ثم يحصل على صفحة عامة قابلة للمشاركة. تجمع المنصة المشاريع والإنجازات ومسار التعلم والسيرة الذاتية في مكان واحد، بدل توزيعها بين روابط وملفات متفرقة.

بدأ المشروع كبورتفوليو شخصي باسم **MyDevFolioHub**، ثم تطور إلى منصة متعددة المستخدمين بهوية **Deviloq**. بقي الهدف كما هو: مساعدة الشخص على عرض ما أنجزه، وما يعمل عليه الآن، وكيف يتقدم بمرور الوقت.

## لماذا قد تستخدمه؟

- **للطلاب والمطورين:** صفحة واحدة للمشاريع والمختبرات والمهارات والتعليم والشهادات والإنجازات.
- **لتوثيق التعلم:** سجل تعلم، موضوعات تتعلمها حاليًا، أهداف وموارد توضح تقدمك خارج المشاريع النهائية.
- **للتقديم على الفرص:** رابط عام للبورتفوليو واستوديو لإنشاء سيرة ذاتية مع معاينة A4 وقائمة مراجعة للجاهزية وATS.
- **لاكتشاف الآخرين:** صفحة مجتمع تعرض البورتفوليوهات العامة وتتيح البحث والتصفية حسب التخصص.

## أبرز الميزات

- لوحة تحكم لإدارة الملف والمحتوى، مع مؤشر اكتمال وتحليلات للمشاهدات عند توفر بياناتها.
- تخصيص ثيم البورتفوليو وترتيب أقسامه، مع معاينة للتغييرات أثناء التحرير.
- عرض أبرز المستودعات واللغات البرمجية العامة من GitHub عند ربط حساب المستخدم.
- صفحات عامة للمشاريع والمختبرات وسجل التعلم والتعليم والشهادات والتوصيات ووسائل التواصل.
- واجهة عربية وإنجليزية، تدعم اتجاه **RTL** وتتكيف مع الكمبيوتر والتابلت والجوال.
- تطبيق ويب قابل للتثبيت (**PWA**) مع صفحة بديلة عند انقطاع الاتصال، وتطبيق Android مبني من الواجهة نفسها.

## كيف بُني المشروع؟

بُني Deviloq كتطبيق ويب يعتمد على **HTML وCSS وJavaScript**، دون إطار واجهات ثقيل. تتولى الواجهة عرض الصفحات والتفاعل والتبديل بين اللغات والثيمات. يستخدم المشروع **Supabase** للمصادقة والبيانات والملفات، ويقرأ بيانات GitHub العامة لعرض أبرز أعمال المستخدم. تُنشر ملفات الويب الثابتة عبر **GitHub Pages**، ثم تُنسخ الواجهة نفسها إلى تطبيق Android باستخدام **Capacitor**.

| الجزء | التقنية ودورها |
| --- | --- |
| الواجهة | HTML وCSS وJavaScript للصفحة الرئيسية والمجتمع والبورتفوليو ولوحة التحكم |
| البيانات والحسابات | Supabase Auth وDatabase وStorage |
| تكامل GitHub | GitHub API لعرض المستودعات واللغات العامة |
| الويب القابل للتثبيت | Web Manifest وService Worker لملفات التطبيق العامة وصفحة عدم الاتصال |
| Android | Capacitor مع مشروع Gradle وAPK موقّع للإصدارات الرسمية |
| التحقق | Playwright لاختبار التدفقات العامة والجوال والعربية وRTL وعدم التمدد الأفقي |

رحلة المستخدم باختصار: **ينشئ حسابًا ← يضيف محتواه من لوحة التحكم ← يحفظه في Supabase ← يشاركه عبر رابط بورتفوليو عام**. يستخدم تطبيق Android ملفات الواجهة نفسها، ولذلك تصل تحسينات التصميم إلى الويب والجوال معًا عند إصدار نسخة جديدة.

## تشغيل الواجهة محليًا

يتطلب المشروع **Node.js** وnpm. يستخدم سير البناء الآلي Node.js 24.

```bash
npm ci
node scripts/serve-site.cjs
```

افتح `http://127.0.0.1:4173/`. ولتشغيل اختبارات الواجهة باستخدام Playwright:

```bash
npm run test:e2e
```

الواجهة العامة يمكن معاينتها محليًا، لكن وظائف الحساب والمحتوى تحتاج اتصالًا بخدمة Supabase المرتبطة بالمشروع. لا يحتوي المستودع على إعداد قاعدة البيانات الكامل لمشروع Supabase مستقل؛ يوجد ضمن `sql/` ترحيل خاص بمحتوى السيرة الذاتية.

## بناء تطبيق Android

```bash
npm run mobile:sync
npm run mobile:apk
```

الأمر الأول ينسخ ملفات الويب إلى مشروع Android، والثاني يبني APK تجريبيًا. بناء **APK رسمي قابل لتحديث النسخ السابقة** يحتاج مفتاح التوقيع الثابت وإعداداته المحلية؛ راجع [دليل إصدار Android](./ANDROID_RELEASE.md). لا تُرفع مفاتيح التوقيع أو كلمات المرور إلى المستودع.

## هيكل الملفات

```text
index.html          واجهات الموقع والتطبيق
css/                التنسيقات والخطوط
js/                 منطق الواجهة والحسابات والميزات
assets/             الهوية البصرية والخطوط والأيقونات
sql/                ترحيلات قاعدة البيانات المتاحة
scripts/            الخادم المحلي وتجهيز ملفات Android
tests/              اختبارات Playwright
android/            مشروع تطبيق Android
sw.js               تخزين ملفات الويب العامة للاستخدام دون اتصال
```

## ملاحظات حول المشروع

- المحتوى الخاص بالحسابات يتطلب اتصالًا بالشبكة؛ صفحة عدم الاتصال لا تعني أن التحرير والحفظ يعملان دون إنترنت.
- الإصدارات الرسمية لأندرويد تستخدم توقيعًا ثابتًا ورقم إصدار متزايدًا حتى يمكن تثبيتها كتحديث دون حذف التطبيق.
- تراخيص الموارد المضمّنة موثقة في ملفاتها، ومنها تراخيص الخطوط والأيقونات، إضافة إلى [ترخيص ملفات HTML5 Boilerplate](./LICENSE.txt).

### English summary

**Deviloq** is a bilingual developer portfolio platform for publishing projects, skills, learning progress, credentials, and a tailored resume through one shareable profile. It began as a personal portfolio called MyDevFolioHub and grew into a multi-user product. The web interface uses HTML, CSS, and JavaScript; Supabase provides authentication, data, and storage; GitHub supplies public repository highlights; Capacitor packages the same interface for Android. The public website is hosted on GitHub Pages.
